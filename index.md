# CyberGridML Documentation

**CyberGridML** aims to provide a modeling language and associated tooling targeting cyber-physical power grid systems, using **SysML v2**, **CyberGridML concepts**, and web-based engineering tools.

CyberGridML provides modeling capabilities for representing the interaction between electrical grid assets, control functions, software resources, communication media, and computing infrastructure. The goal is to support clearer system architecture descriptions for modern power grids where cyber and physical components are increasingly interdependent.

CyberGridML is intended to foster Model-Based System Engineering for TSOs and DSOs, or any stakeholder interested in the field of power grid control.

## Start here

## The documentation

This documentation is organized in four sections, following the [Diátaxis](https://diataxis.fr/) framework:

- **[Tutorials](tutorials/)** — learning-oriented lessons that take you through your first model.
- **[How-to guides](how-to-guides/)** — step-by-step instructions for a specific task, for users and developers.
- **[Explanation](explanation/)** — the background: power grid functions, the modeling language, the modeling workflow and design choices.
- **[Reference](reference/)** — the precise description of the CyberGridML profile.

[Getting help](getting-help.md) explains where to ask questions and report problems, and [Contributing](contributing.md) explains how to take part in the project.
