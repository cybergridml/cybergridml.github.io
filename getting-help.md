# Getting Help

- **Questions or errors in this documentation**: open an issue on the [documentation repository](https://github.com/aklira/documentation/issues).
- **Problems with the modeler itself** (frontend or backend): open an issue on the [CyberGridML editor repository](https://github.com/cybergridml/cybergridmodel/issues).
- **Developing or deploying the modeler**: start with the [Development Environment Setup](how-to-guides/development-setup.md) and the [Release and Deployment Instructions](how-to-guides/release-and-deployment.md).
